DEVOPS PORTFOLIO — QUICK START

1. Распакуй архив и открой index.html в браузере.
2. Для фото положи изображение рядом с index.html и назови avatar.jpg.
3. В index.html замени ссылки в блоке контактов на свои реальные адреса:
   VK, Telegram, MAX, GitHub и email.
4. Перед публикацией проверь описания проектов и оставь только то, что действительно делал и можешь объяснить на собеседовании.

Сайт статический: HTML + CSS, сборка и серверная часть не нужны.
